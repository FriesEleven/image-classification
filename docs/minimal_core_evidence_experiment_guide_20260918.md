# 投稿前最小核心证据补充指导（2026-09-18）

## 1. 目标与执行边界

目标期刊沿用 The Journal of Supercomputing。本轮只填补两个核心缺口：

1. 共享阈值相对逐模型阈值的实际取舍，以及最差种子目标、类别约束的作用。
2. 同一 A3 checkpoint、同一阈值下的精度—MAC—实际时延完整证据。

不追求全面胜出，不扩展 ImageNet-100、ResNet-18、能耗或移动设备；不重跑全部历史实验。本文件是执行指导，不代表脚本已实现或实验已获结果。编写本文件未启动服务器、训练、推理或计时。

执行前先读根目录 `AGENTS.md` 和 `docs/final_paper_writing_brief_20260908.md`。历史交接关于不启动官方测试的限制不能由本文件自动解除：若选择新增官方测试评估，必须先获得用户对具体数据集、模型和用途的授权。

## 3. M1：共享阈值的直接对照（零训练优先）

### 3.1 队列与数据边界

复用历史完整配方 A4 的开发 logits，不改名为 A3：

| 队列 | Source seeds | Target seeds | 最差类别下降预算 |
|---|---|---|---:|
| CIFAR-10 | 54–56 | 57–59 | 0 pp |
| CIFAR-100 strict | 60–62 | 63–65 | 0 pp |
| CIFAR-100 relaxed | 60–62 | 66–68 | 4 pp |

总体及 balanced accuracy 下降预算均为 0 pp。历史 15% 节省下限保持不变；展示风险可行候选不等于通过全部门槛。Strict 队列失败不得删除，也不得把 relaxed 结果用作修复 strict 的证据。

主评分固定 MSP，ENT/margin 已有结果不需全量重复。本轮所有比较是既有结果已知后的事后开发分析。

为了比较逐模型重校准策略，必须把缓存图像划分为拟合集 F 和审计集 E：按图像 ID 排序后，用固定 PCG64 seed=20260918 进行分层 50/50 拆分。先冻结、保存 ID 和哈希；按 ID 而非数组位置在全部模型中对齐。若每个模型具有同一 5,000 张、类别均衡的校准图像，则 F/E 各 2,500 张；否则记录实际数量并先修订协议。

共享策略只用 source 的 F；逐模型策略只用对应模型的 F；全部 target 策略在相同 E 上审计。E 不能出现在任何 source 拟合输入中。即便这样，图像仍可能在历史分析中被看过，因此只能称“本轮拟合/审计分离”，不能称全新未见图像、前瞻性独立验证或风险保证。

### 3.2 四项策略

| ID | 策略 | 阈值来源 | 选择目标 | Source 约束 |
|---|---|---|---|---|
| S | 共享完整策略 | 所有 source 的 F | 最大化最小 seed MAC 节省 | 每 seed 总体、balanced、最差类别 |
| I | 逐模型独立策略 | 各模型自己的 F | 最大化该模型 MAC 节省 | 该模型总体、balanced、最差类别 |
| A | 共享平均目标 | 所有 source 的 F | 最大化平均 seed MAC 节省 | 与 S 相同 |
| C | 共享去类别约束 | 所有 source 的 F | 与 S 相同 | 每 seed 总体、balanced；移除最差类别约束 |

I 在 source 上展示“单独拟合”的代价/收益，在 target 上展示“每个重训模型都重新标定”的代价/收益。不得将 source 某个 seed 的阈值任意配给 target seed。I 使用了 target 模型的标定信息，S/A/C 没有；因此这是一种允许重校准的参考，不是相同信息条件下的迁移优劣证明。保留每模型标定与维护参数数，不宣称已经测量人工维护成本。

Source 配置参数数：S/A/C 为 1，I 为 3。Target 部署：S/A/C 直接冻结 source 阈值、0 次 target 重校准；I 为每个 target 新标定一次、共 3 个阈值。若 I 某模型不可行，不得丢弃该模型。

### 3.3 候选、选择和成本

- S/A/C 使用完全相同的 source-F pooled MSP 分位数候选：1,001 个分位点，去重，加严格大于最大 score 的全 fallback 候选。
- I 每个模型使用自身 F 的同样 1,001 分位点规则和 fallback 候选；这是相同搜索分辨率，不是完全相同数值网格。记录实际候选数与总搜索量，I 不得额外使用密集搜索。
- S/C 并列时依次选择平均节省更高、阈值更高者；A 并列时依次选择最小 seed 节省更高、阈值更高者；I 并列选阈值更高者。
- 将可行性判断容差冻结为 `1e-12`（比例单位），不得在看结果后放宽；显示单位为 % 或 pp。
- 先检查风险，再检查预设节省下限，分别保存 `risk_feasible` 和 `saving_floor_pass`。全 fallback 可作为风险参照，但通常不能通过节省下限。
- MAC 以同 checkpoint 的 final-only 为参照，保留未早退样本计算 exit8 head 的额外成本。复用 `corrected_saving` 的口径并用手算例核对，不能使用历史遗漏 fallback overhead 的代理量。
- Conv/Linear MAC 不包含 MSP 算子成本，不能解释为实际时延。

### 3.4 输出与解释

必须生成逐 seed 记录和汇总：final/policy accuracy、balanced accuracy、最差类别下降、早退率、校正 MAC 节省、候选数、阈值、各风险判定、节省下限判定、参数数、重校准次数、数据范围、模型配方及哈希。

主表分 source-F 拟合与 target-E 审计两面板，保留三队列和全部四策略。主图使用 target-E 的总体精度下降—MAC 节省散点，类别预算失败另用标记，不能把离散点平滑为完整 Pareto 曲线。

S 与 I 的共享代价、S 与 A 的最差 seed 取舍、S 与 C 的类别风险取舍分别报告，不要求 S 全胜。若几乎没有差异，诚实给出差异大小；若共享策略明显更差且无可量化价值，收缩贡献或停止扩展，而不是继续寻找更好看的预算。

## 4. M2：A3 精度—MAC—时延完整工作点

### 4.1 冻结对象

历史 P8-v3 对象：CIFAR-10 A3 seeds 54/55/56，阈值 0.984；CIFAR-100 A3 seeds 66/67/68，阈值 0.903。这些不是全部新的 source→target 迁移模型，尤其 CIFAR-10 使用历史 source seeds；本项验证同模型性能点，不新增共享阈值迁移结论。

确认实际 checkpoint 与历史 receipt 相符，不能只根据 experiment 名称判断。部署仅 exit8 决策，exit16 是训练辅助头；参照为同一 A3 checkpoint 的 final-only，不是独立 A0。阈值不再拟合或搜索，也不根据官方精度挑选模型。

### 4.2 默认路线：授权后锁定评估现有官方测试

先取得用户对“两数据集、六个固定 checkpoint、两个固定阈值、一次锁定官方测试评估”的明确授权。检查该测试集是否已在项目历史中被其他模型/方法查看，按事实登记曝光情况。

1. 在全部官方测试图像上评估同 checkpoint 的 final、exit8 和锁定 policy，保存图像 ID、标签、各预测、路由与必要分数。
2. 计算总体/balanced accuracy、逐类别精度、相对自身 final 的最差类别下降、早退率和校正 MAC 节省。保留所有失败。
3. 即便 A3 第一次评估该测试集，也只称“锁定模型在既有官方 benchmark 上的补充评估”；不能称项目完全未接触的独立确认。
4. 如需真正新数据确认，应先另定数据方案、预算和授权，不把已有数据重新拆分后宣传为全新独立证据。

已有 P8/20260908 时延使用训练池中的校准图像。可把旧时延作为另一个明确标注的数据范围保留，但不能把旧校准时延与新 official 精度/MAC 放在同一行，暗示来自同一工作负载。

### 4.3 最小同工作负载计时

新增时延主场景固定为 RTX 3080 Ti、batch=1、六个 A3 checkpoint；主要对比仅 final-only 与 actual_dynamic。输入来自上述锁定官方评估集，使用同一确定性顺序；循环/子集的 ID、样本次数和路由分布全部保存。

- FP32，关闭 matmul/cuDNN TF32，继承 P8-v3 确定性及容差设置；记录 CPU/GPU 和实际软件环境。
- 每 seed 五个配对轮次，每模式 100 次 warm-up、1,000 次计时；模式顺序配对随机化。CUDA 采用事件或严格同步，不使用未同步墙钟值。
- 计时调用外执行正确性审计，核对真实 dynamic 路由、argmax 与对应 reference logits；本轮要求检查范围内 0 个路由和 argmax 不一致，容差冻结为 rtol=1e-4、atol=1e-5。
- 精度对全测试集统计；计时对指定 resident-input 工作负载统计。完整工作点须标明二者均来自该测试集，但计时若为子集/循环不能声称每图都计时。
- 工作负载分布用独立非计时审计核对早退率与 MAC；不把计时子集 MAC 直接当成全测试集 MAC，不用校准早退率替代测试早退率。
- 范围仅模型执行，不含预处理、传输、队列和服务时延。时延 mean/p95、吞吐和节省分别报告；负收益完整保存。

不重跑 CPU 和全部大 batch。旧的大 batch 减速、CPU 结果和两次历史 GPU 复测继续保留，明确不是本次新工作负载的重复测量。官方测试若不获授权，本项标为 blocked；可另行获得授权后做开发集完整工作点，但不能宣布独立精度缺口已经填补。

## 5. M3：统计、审计与交付

### 统计规则

- 三个训练 seed 为模型层面的三个单位，不能用计时调用数当 n。主表显示全部 seed、均值和 sample SD，n=3 的局限保留。
- 精度比较始终配对到相同模型/图像。可进行 2,000 次分层配对图像 bootstrap，报告条件于这三个固定模型的总体精度差 95% 区间，注明历史曝光和开发选择不能由 bootstrap 消除。
- 最差类别是最大值统计量：报告逐类别原始计数和经验最大下降；不把一般 bootstrap 区间称为多类别同时风险保证。
- 时延先求每 seed 配对轮次的节省，再跨 seed 汇总；不能用不同模式/不同 seed 的混合均值替代配对效应。可附每 seed 轮次配对区间，但明确不等于重训练总体的区间。
- 本轮不要求显著性胜出；样本过少或区间过宽也属于结果。固定 bootstrap RNG seed=20260918，不反复换统计方法追求显著。

## 6. 执行顺序和停止规则

1. M0 只读盘点，列出缺项和待授权项，冻结协议；没有必需输入就停止，不自动恢复下载或重训。
2. 实现 M1 新分析入口，先进行不接触官方测试的边界/手算检查，再执行缓存比较。
3. 审查 M1：负结果不触发删除或重选预算；若贡献价值很弱，先与用户确认是否仍投入 M2。
4. 确认 M2 授权和 checkpoint 后实现锁定评估与最小计时，不复用历史启动器默认目录。
5. M3 审计、整理交付；只有输入、正确性和数据边界检查通过的结果可进入论文。

实现错误、输入哈希不符、数据 ID 错位、拟合/审计重叠、checkpoint 不符或正确性不通过时，停止后续阶段并保存失败。修复须另开输出目录、记录协议版本，不把失败运行静默替换。科学负结果不等于技术执行失败，不允许自动重试到正结果。
